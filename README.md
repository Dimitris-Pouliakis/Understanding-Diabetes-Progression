# Understanding-Diabetes-Progression
Based on linear and multi model, of different variables BMI (Body Mass Index), BP (Blood Pressure), Age and S5 (Serum 5 Measurement), we tried to associate these independent variables to an output dependent variable, the progression of the diabetes score



Here you find a full analysis on the report pdf with name "Final Assignment Report - Dimitrios Pouliakis". The analysis achieved with R programming language as a strong tool to analyze health care data. The source of the dataset is: **https://www4.stat.ncsu.edu/%7Eboos/var.select/diabetes.tab.txt**

You can find the raw code and a R markdown file, if you are interested to modify or check on your own the code, or either you are interested in a more readable approach correspondingly
This is a starting analysis for education purposes for the seminar "Data Analysis and Statistics" @AUTH 2026.

Also, a powerpoint file provided, to communicate the most important findings and points from the analysis. Although, there are a lot of limitations, in the study, optimization of the model, studying model based on different variables, study further multicollinearity, non-linear effects and maybe accessing a bigger dataset.

# Dataset
Diabetes Progression Observations: 442 patients
Outcome: Continuous measure of disease progression one year after baseline
Predictors: Age, sex, BMI, blood pressure and six serum measurements Analysis software
R Source : NCSU-hosted copy of the diabetes dataset
